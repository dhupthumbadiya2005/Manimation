Right now, making a good educational animation -like the ones on 3Blue1Brown -requires a
person who knows both the subject and a programming library called Manim. That's a rare
combination, so almost nobody can do it. Our project builds an AI system that takes a topic in
plain English ("explain binary search") and produces the finished animated video automatically,
by having one AI agent plan the video like a director, another AI agent write the actual animation
code like a programmer, and a third component check the rendered result and fix it if something
looks wrong -closing the loop without a human in it.
